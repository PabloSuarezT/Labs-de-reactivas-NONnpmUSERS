Instrucciónes generales para iniciar e2e:

Primero debemos crear la carpeta mediante los siguientes comandos:

```cmd
mkdir e2e-tests
cd e2e-tests 
´´´

Luego, debemos instalar playwright:

```cmd
npm init playwright@latest
´´´

Finalmente, para corroborar los test, simplemente ejecutamos:

```cmd
npm test
´´´
